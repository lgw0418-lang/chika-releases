# Chika Android release archives

Official, byte-preserved Chika Android APK and incremental patch artifacts.

For the current supported app and installation instructions, use **https://chika.world/**. These archive releases are not a replacement for the current in-app update channel.

- APK files retain their original signatures and content hashes.
- Existing download URLs and app-update metadata remain supported.
- Incremental patches are valid only for the exact matching installed APK.
- Do not uninstall the app merely to update it. Do not install an older archive over a newer app.

This repository contains release artifacts and public documentation only. It does not contain the private application repository, environment files, application signing keys, server credentials, user media, or server backups.

Unchanged third-party SDK binaries remain part of their original signed APKs under their respective licenses.
